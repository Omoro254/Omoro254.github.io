# 🚀 Deployment Guide

## Option 1 – GitHub Pages

1. Upload `index.html` to your repository  
2. Go to **Settings → Pages**  
3. Select `main` branch  
4. Save  
5. Your site will deploy automatically  

---

## Option 2 – Netlify

1. Go to netlify.com  
2. Drag and drop your project folder  
3. Deploy instantly
